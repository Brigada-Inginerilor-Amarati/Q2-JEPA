# TaxiBJ: CNN vs ViT twin vs HQViT

TaxiBJ crowd flow ([candidate datasets spec §5](../superpowers/specs/2026-11-21-q2jepa-candidate-datasets.md)), test
split (500 samples), 128 prior draws each, seeds 0–2. One recorded future per sample, so there is no coverage,
validity or TV. Preset `+experiment=taxibj` (64×64, `input_norm=l2`). No tuning of its own: all three encoders use
MovingMNIST's dev-tuned schedule, `+tune=s1`. HQViT trains with `quantum.hqvit_train=torch` (exact torch simulation)
and is evaluated through the CUDA-Q circuits.

**Reproduce:** `python scripts/run_grid.py --bench taxibj --stage grid --seeds 0 1 2 --jobs 3` at commit **b2d62d3**.
One run is `python -m q2jepa.train +experiment=taxibj +tune=s1 eval.split=test encoder=<cnn|vit|hqvit>
prior=<softmax_categorical|entangled_qcbm> seed=<0|1|2> quantum=gpu trainer.device=cuda`, plus
`quantum.hqvit_train=torch` for HQViT. Data: `python scripts/fetch_taxibj.py`.
The grid stage reads the schedule from the MovingMNIST tuning runs, which must be under `--root`
([encoders page](2026-11-phase2-mmnist-encoders.md)). Reference rows: `python scripts/taxibj_baselines.py --split test`, in the
commit that adds this page.
**Platform:** Colab T4, `nvidia` target. Seed-0 runs were interrupted and resumed from checkpoints.

Errors are per value on the [0, 1] scale, in units of 10⁻³ (`mae_min` and ES too). They are not OpenSTL's per-frame MSE.
`mse_min` is the best of 128 draws (an oracle); compare `mse_mean` with the reference rows.

**Reading.**
- Every run has a lower `mse_mean` (0.77–1.30) than copying the last map (1.68): 33–44% lower on the row means.
- HQViT's mean error is below its classical twin's with both priors, but the twin is better on seed 2 with both, so
  3 seeds show no sign that HQViT is worse and no evidence that it is better. HQViT and CNN are level.
- Entangled-QCBM and Softmax-Categorical are level for every encoder, as expected with a single future.
